# DESIGN.md - Loboczss Portfolio

## 1. Design Philosophy: The Neural Architect
The Creative North Star is "The Neural Architect." 
Sophistication, AI energy, and atmospheric depth through a "Liquid Precision" aesthetic.

## 2. Key Elements
- **Cosmic Foundation:** Deep dark backgrounds (`surface: #0b1326`).
- **Signature Textures:** Indigo-Emerald gradients and glassmorphism.
- **Editorial Authority:** Extreme scale contrast in typography (Inter font).
- **Asymmetric Layouts:** Intentional "breathing room" with large spacing.

## 3. Colors & Tokens
- **Background:** #0b1326
- **Primary:** #4f46e5 (Indigo)
- **Secondary:** #10b981 (Emerald)
- **Highlights:** Glass at 60% opacity with 20px blur.

## 4. Typography Hierarchy
- **Display LG:** 3.5rem (Semibold, -0.02em letter spacing)
- **Headline MD:** 1.75rem
- **Body LG:** 1rem (1.6 line height)

## 5. UI Elements
- **Buttons:** Rounded-full (xl). Primary with gradient.
- **Cards:** No borders. Separate sections by background shifts (Tonal Layers).
- **AI Tags:** Small chips with terminal/code feel.

## 6. Design System Notes for Stitch Generation (Required for all Prompts)
**CRITICAL:** Designers are prohibited from using 1px solid borders. Boundaries must be defined solely through background color shifts. Use deep, cosmic foundations (#0b1326) and Indigo (#4f46e5) / Emerald (#10b981) gradients. Incorporate "Glassmorphism" for navigation/overlays (60% opacity surface + 20px blur). Typography should rely on extreme scale contrast using the Inter font. Ensure generous spacing (e.g., 2.25rem margins) and asymmetrical layouts to create an editorial, visionary vibe.
